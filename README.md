# ORVIO Production Operating System (OPOS)

> The official production operating system for the ORVIO YouTube channel.

---

## What is OPOS?

ORVIO Production Operating System (OPOS) is not a style guide.

It is a complete production operating system designed to ensure that every AI model follows the exact same workflow when creating videos for the ORVIO channel.

The goal is to eliminate inconsistency, improvisation and subjective decisions.

Every video produced under OPOS must follow the documented production pipeline.

# Production Philosophy

The AI is not expected to be creative by default.

The AI is expected to execute the production system exactly as documented.

If information required by the system is missing, the AI must stop and ask the user before continuing.

---

# Project Goals

- Standardize every production step.
- Keep visual consistency.
- Create reusable production workflows.
- Build a permanent knowledge base.
- Make every AI behave like a trained ORVIO production team member.
