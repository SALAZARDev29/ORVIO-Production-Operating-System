# 00_Core

> Foundation of the ORVIO Production Operating System (OPOS)

---

# Purpose

The **Core** module defines the permanent operating principles of OPOS.

Every AI model must complete this module before reading any other documentation.

This module establishes:

- AI identity
- Mission
- Core rules
- Workflow
- Decision system
- Production stages
- Terminology

Without these documents, no production activity should begin.
