# Naming Conventions

## Purpose

This document defines how files, folders and documents are named inside OPOS.

---

## Folder Names

Use:

00_System

01_Core

02_Topic_Engine

03_Script_Engine

04_Content_Block_Engine

05_Visual_Engine

06_Motion_Engine

07_Character_Engine

08_Background_Engine

09_Google_Flow_Engine

10_Editing_Engine

11_Quality_Engine

12_Templates

13_Examples

---

## File Names

Use uppercase letters with underscores.

Examples:

AI_IDENTITY.md

MISSION.md

CORE_RULES.md

WORKFLOW.md

DECISION_ENGINE.md

---

CORE-001

---

## Rule

Never rename files unless absolutely necessary.

Keep naming consistent across the entire project.
