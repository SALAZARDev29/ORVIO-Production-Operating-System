# Versioning

## Purpose

This document explains how OPOS versions are managed.

---

## Version Format

MAJOR.MINOR.PATCH

Example:

1.0.0

---

## Major Version

Increase when major changes affect the system.

Example:

1.0.0 → 2.0.0

---

## Minor Version

Increase when new features or modules are added.

Example:

1.0.0 → 1.1.0

---

## Patch Version

Increase when fixing errors or improving documentation.

Example:

1.0.0 → 1.0.1

---
