---

## Rules

- Every module has its own folder.
- Every folder contains a README.md explaining its purpose.
- Files inside a folder should follow a logical reading order.
- Do not place unrelated documents in the same folder.
- Keep the repository clean and organized.

---

## Goal

Anyone opening the repository should immediately understand where to find any document.
