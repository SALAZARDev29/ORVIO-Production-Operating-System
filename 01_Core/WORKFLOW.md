# PURPOSE

This document defines the official production workflow used by ORVIO.

Every production task must follow this workflow.

No stage may be skipped.

---

# OVERVIEW

Every video moves through the following stages:

TOPIC

↓

SCRIPT

↓

CONTENT BLOCKS

↓

VISUAL PLANNING

↓

ASSET VALIDATION

↓

GOOGLE FLOW PROMPTS

↓

EDITING

↓

QUALITY CONTROL

↓

FINAL VIDEO

---

# STAGE 01 — TOPIC

Objective:

Select a topic suitable for ORVIO production.

Requirements:

- Clear subject
- Strong visual potential
- Documentary value
- Sufficient information available

Output:

Approved Topic

---

# STAGE 02 — SCRIPT

Objective:

Transform the topic into a structured narrative.

Requirements:

- Clear introduction
- Logical flow
- Strong retention
- Documentary tone

Output:

Approved Script

---

# STAGE 03 — CONTENT BLOCKS

Objective:

Split the script into production blocks.

Typical structure:

👤 Person

📍 Location

⚙️ Machine / Place

🏭 Purpose

🔄 How It Works

⚠️ What Happened

📌 Result

Output:

Approved Content Blocks

---

# STAGE 04 — VISUAL PLANNING

Objective:

Determine visual requirements.

Questions:

- Is a reference character required?
- Is a reference background required?
- Is continuity required?
- Are reusable assets available?

Output:

Visual Production Plan

---

# STAGE 05 — ASSET VALIDATION

Objective:

Verify required assets.

Examples:

- Character reference
- Background reference
- Existing templates

Output:

Validated Asset List

---

# STAGE 06 — GOOGLE FLOW PROMPTS

Objective:

Generate production prompts.

Rules:

- One prompt per section
- One storyboard sheet per prompt
- No unnecessary complexity
- Follow OPOS visual standards

Output:

Approved Prompt Package

---

# STAGE 07 — EDITING

Objective:

Assemble visual assets.

Tasks:

- Arrange sequences
- Synchronize narration
- Maintain pacing
- Preserve continuity

Output:

Draft Video

---

# STAGE 08 — QUALITY CONTROL

Objective:

Verify compliance.

Checks:

- Script quality
- Visual consistency
- Motion consistency
- OPOS compliance

Output:

Approved Production

---

# STAGE 09 — FINAL VIDEO

Objective:

Publishable video package.

Output:

Final Video

---

# WORKFLOW RULES

RULE-WF-001

Never start a stage before completing the previous stage.

---

RULE-WF-002

Never generate prompts before visual planning.

---

RULE-WF-003

Never begin editing before prompt generation is complete.

---

RULE-WF-004

Never skip quality control.

---

RULE-WF-005

If a stage fails validation:

STOP.

Return to the previous stage.

Correct the issue.

Resume production.
