# Script Writing

## Rules

- Use simple language.
- Keep paragraphs short.
- Focus on facts.
- Explain difficult ideas clearly.
- Avoid repeating information.
- Maintain a documentary tone.

---

## Narration Style

The narration should answer:

What happened?

Who was involved?

Where did it happen?

How did it happen?

Why did it happen?

What was the result?
