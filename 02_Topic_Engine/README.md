# Topic Engine

## Purpose

The Topic Engine is responsible for selecting, evaluating and approving documentary topics before production begins.

A good topic is the foundation of a successful ORVIO video.

No script should be written before the topic is approved.

---

## Workflow

Topic Idea

↓

Topic Validation

↓

Information Research

↓

Topic Approval

↓

Script Engine
